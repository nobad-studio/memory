Maintainer asked (2026-11-17): VPN bug reports, releases, advisories and the VPN page link to `nobad-studio/Nobad-VPN`;
File Bridge links to `nobad-studio/file-bridge`; footer/nav "GitHub", contributing guide, security policy,
contributors and "source code" link to the organization (`github.com/nobad-studio`, `nobad-studio/.github`,
`orgs/nobad-studio/people`). Status text must match reality: a released product never says "in development".

**Why:** NOBAD is a studio with several products; sending everyone to the VPN repo looked like a one-product project.
**How to apply:** when adding a link, ask "is this about one product?" If not, link the organization.
